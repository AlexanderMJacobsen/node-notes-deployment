Git is a versioning tool used to manage versions of code or data.

To start a Git project, write the following inside a Dir you would like to start verisoning:

git init

Now whenever you make changes, you can now use the following command to view new changes.

git status

Example output:

On branch development Your branch is ahead of 'origin/development' by 3 commits. (use "git push" to publish your local commits) Changes not staged for commit: (use "git add ..." to update what will be committed) (use "git restore ..." to discard changes in working directory) modified: public/pages/terminal/git.html

Now we will start the staging process, which is the process of adding, committing and pushing your code to a remote repo

First we add a new file with:

git add "filename"

After we have added a file, it is now time to commit, where we also write commit messeages, it is a good idea for good overview to write clean commit messeages

git commit -m "feat: added "filename" to project

We are now ready for the final step which is pushing to a remote repository, if you haven't already used git clone on a remote project, you can now point at one with git remote:

git remote set-url origin https://github.com/username/example.git

If you have your remote repository set you can now push the code with:

git push
